# Chicken Loot

The Server modifies the loot table of Chicken, allowing them to drop [[mc:Feather|Feathers]] instead of an egg at times.

## How it works

Using a Datapack, the loot table of chickens was modified to include feathers as an item with a drop chance of `0.25`, giving a ~25% chance of a feather being dropped instead of a chicken egg.
