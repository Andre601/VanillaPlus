# Food

VanillaPlus provides various food items that can be caught, crafted or obtained to replenish your saturation and hunger.

/// html | div.grid.cards
-   ### [[Baked Apple]]
    
    Baked Apple is a food item that can be obtained by cooking an Apple in the Furnace or Smoker.

-   ### [[Cherry]]
    
    Cherry is a food item which can randomly drop from breaking Cherry Leaves.

-   ### [[Lava Carp]]
    
    Lava Carp is a consumable item that can be obtained when fishing in Lava Lakes in the Nether using the [[Iron Fishing Rod]].
